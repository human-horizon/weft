# Specification: vitest.config.ts

## Обзор

Файл конфигурации Vitest для проекта Human Horizon. Определяет настройки запуску тестов.

---

## Публичный API

### Экспорт конфигурации

- `export default` — экспортирует объект конфигурации Vitest, созданный через `defineConfig` из `vitest/config`.

---

## Настройки тестов

### `test.include`

- **Тип**: `string[]`
- **Значение по умолчанию**: `['tests/**/*.test.ts']`
- **Описание**: Паттерны файлов, которые должны быть включены для запуска тестов.
- **Поведение**:
  - Поддерживает стандартные шаблонные выражения glob.
  - Тесты находятся в директории `tests`.
  - Файлы должны иметь расширение `.test.ts`.

### `test.environment`

- **Тип**: `string`
- **Значение по умолчанию**: `'node'`
- **Описание**: Определяет среду выполнения для тестов.
- **Допустимые значения**:
  - `'node'` — Node.js (текущее значение)
  - `'jsdom'` — для браузерных тестов
  - `'happy-dom'` — альтернативный браузерный DOM
- **Поведение**:
  - `'node'` обеспечивает доступ к модулям Node.js и глобальным переменным (`process`, `Buffer` и т.д.).

### `test.globals`

- **Тип**: `boolean`
- **Значение по умолчанию**: `false`
- **Описание**: Определяет, должны ли глобальные функции Vitest (например, `test`, `describe`, `expect`) быть доступны в глобальной области видимости.
- **Поведение**:
  - `false` — функции должны быть импортированы явно из `vitest`.
  - `true` — функции доступны глобально.
  - Текущее значение требует явного импорта: `import { test, describe, expect } from 'vitest'`.

---

## Типы

### `Config`

Неявно используемый тип конфигурации Vitest, определяемый через `defineConfig`.

```typescript
interface Config {
  test: {
    include: string[];
    environment: string;
    globals: boolean;
    // Дополнительные настройки могут быть добавлены в будущем
  };
}
```

---

## Детали реализации

### Импорты

- `import { defineConfig } from 'vitest/config'` — используется для создания конфигурационного объекта с поддержкой hot reloading.

### Структура экспорта

Файл экспортирует объект по умолчанию, который является результатом вызова `defineConfig()`. Это позволяет конфигурации быть перезагружаемой при изменении.

---

## Ограничения

- Тесты должны следовать паттерну `tests/**/*.test.ts`.
- Используется среда `'node'`, поэтому браузерные API недоступны без дополнительных настроек.
- Глобальные функции Vitest не доступны — требуется явный импорт.

---

## Примеры использования

### Запуск тестов

```bash
pnpm test
pnpm test -- --run
pnpm test -- tests/some.test.ts
```

### Импорт в тестовом файле

```typescript
import { test, describe, expect } from 'vitest';

describe('example', () => {
  test('works', () => {
    expect(1 + 1).toBe(2);
  });
});
```
