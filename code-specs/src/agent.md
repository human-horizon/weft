# Specification: `src/agent.ts`

## Обзор

Модуль `agent.ts` обеспечивает интерфейс для взаимодействия с внешним кодовым агентом (PI Coding Agent). Модуль управляет:

- Загрузкой и настройкой пути к агенту
- Очисткой сессионных файлов после выполнения
- Разрешением тегов моделей с учётом конфигурации пользователя
- Вызовом агента через JSON-моду с обработкой потоковых событий

---

## Публичный API

### `setAgentPath(path: string)`

Устанавливает кастомный путь к исполняемому файлу агента.

**Параметры:**

| Параметр  | Тип   | Описание                                           |
|-----------|-------|----------------------------------------------------|
| `path`    | `string` | Полный путь к исполняемому файлу агента.          |

**Эффекты:**

Изменяет внутреннее состояние — записывает новый путь в переменную `agentPath`.

---

### `clearSessions()`

Удаляет все сессионные файлы, созданные агентом.

**Описание:**

- Очищает директорию сессий в `{agentDir}/sessions/<encoded-cwd>/*.jsonl`.
- Удаляет файлы `.jsonl` и пустые директории.

**Эффекты:**

Изменяет файловую систему — удаляет сессионные файлы.

---

### `resolveModel(tag: string): string`

Преобразует тег модели в полное имя модели.

**Параметры:**

| Параметр  | Тип      | Описание                                                                     |
|-----------|----------|------------------------------------------------------------------------------|
| `tag`     | `string` | Тег модели (например, `"free"`, `"fast"`), полное имя (`"provider/name"`), или имя из конфигурации. |

**Возвращаемое значение:**

`string` — полное имя модели.

**Исключения:**

Бросает `Error`, если тег неизвестен и не выглядит как полное имя (не содержит `/`).

**Правила разрешения:**

1. Сначала проверяется кэш — если `tag` уже разрешён, возвращается сохранённое значение.
2. Загружается `~/.ai/settings.json` — если `tag` указан в `modelMapping`, возвращается его значение.
3. Если `tag` содержит `/`, считается полным именем и возвращается как есть.
4. В противном случае бросается ошибка.

---

### `invokeAgent(prompt: string, opts: {})`

Выполняет запрос к агенту и получает результат в виде `AgentResult`.

**Параметры:**

| Параметр  | Тип      | Описание                                                                  |
|-----------|----------|---------------------------------------------------------------------------|
| `prompt`  | `string` | Текст запроса для агента.                                                 |
| `opts`    | `object` | Опциональные параметры вызова (см. таблицу ниже).                         |

**Опции:**

| Параметр        | Тип      | Описание                                                         |
|-----------------|----------|------------------------------------------------------------------|
| `session`       | `string` | Идентификатор сессии (опционально).                              |
| `model`         | `string` | Тег или имя модели для использования.                             |
| `thinking`      | `string` | Режим thinking (опционально).                                     |
| `signal`        | `AbortSignal` | Сигнал прерывания для отмены вызова (опционально).             |

**Возвращаемое значение:**

`Promise<AgentResult>` — результат выполнения с:

- `stdout` — текст вывода агента
- `stderr` — текст ошибок
- `exitCode` — код завершения процесса
- `duration` — время выполнения в мс
- `ok` — `true`, если завершение с кодом `0`

---

## Типы

### `AgentResult`

Интерфейс результата выполнения агента.

| Свойство       | Тип        | Описание                                              |
|----------------|------------|-------------------------------------------------------|
| `stdout`       | `string`   | Текст вывода агента.                                  |
| `stderr`       | `string`   | Текст ошибок агента.                                  |
| `exitCode`     | `number`   | Код завершения процесса.                               |
| `duration`     | `number`   | Время выполнения в миллисекундах.                      |
| `ok`           | `boolean`  | `true`, если процесс завершился с кодом `0`.          |

## Внутренний API

### `clearSessions()`

(Дубликат публичного API — здесь описывается внутренняя реализация.)

**Описание:**

- Проходит по всем директориям в `{agentDir}/sessions/`.
- Для каждой директории удаляет файлы `.jsonl`.
- Удаляет пустые директории рекурсивно.

---

### `loadModelMapping(): Record<string, string>`

Загружает карту тегов моделей из `~/.ai/settings.json`.

**Описание:**

- Возвращает кэшированный результат после первого вызова.
- Если файл не существует или не содержит `modelMapping`, возвращается пустой объект `{}`.

**Возвращаемое значение:**

`Record<string, string>` — словарь тегов → полных имён моделей.

---

### `buildCliArgs(prompt: string, opts: {})`

Конструирует массив аргументов CLI для вызова агента.

**Параметры:**

- `prompt` — текст запроса
- `opts` — объект с опциями `session`, `model`, `thinking`

**Возвращаемое значение:**

`string[]` — массив аргументов для `spawn()`.

---

### `invokeJsonMode(args: string[], signal?: AbortSignal)`

Выполняет CLI-процесс с парсингом JSON-событий.

**Описание:**

- Запускает `spawn(agentPath, args, ...)`.
- Парсит JSON-строки из `stdout`.
- Обрабатывает события потокового вывода:
  - `thinking_delta` — пишет текст в `stderr` (ANSI-градиент)
  - `text_delta` — пишет текст в `stdout`
  - `text_end` / `message_end` — собирает финальный текст
- Завершается по `close` или `error` событиям.

**Возвращаемое значение:**

`Promise<AgentResult>` — результат выполнения.

---

### `processEvent(line: string)`

Парсит и обрабатывает одну строку JSON-события.

**Описание:**

- Парсит строку в `JsonEvent`.
- Обрабатывает события `thinking_*` и `text_*`.
- Собирает финальный текст из `message.content`.

---

## Внутренние структуры данных

### `JsonEvent`

Интерфейс JSON-события от агента.

| Свойство                | Тип           | Описание                                           |
|-------------------------|---------------|----------------------------------------------------|
| `type`                  | `string`      | Тип события.                                       |
| `message`               | `object`      | Сообщение с ролями и контентом (опционально).     |
| `assistantMessageEvent` | `object`      | События ассистента (thinking/text).                |
| `[key: string]`         | `unknown`     | Доп. поля.                                         |

## Конфигурация

### `WEFT_PI_HOME`

Путь к домашней директории агента:

```typescript
process.env.WEFT_PI_HOME || join(homedir(), ".ai", "weft", "pi")
```

### `VALID_TAGS`

Набор допустимых тегов моделей:

```
free, cheap, fastest, fast, simple, medium, high, xhigh, expert, ultra
```

## Ошибки

### `Error: Unknown model tag`

Бросается, когда:

- Тег не найден в `modelMapping`.
- Тег не содержит `/` (не является полным именем).

---

## Важные замечания

1. **Кэширование `modelMapping`** — загрузка происходит один раз и результат кэшируется.
2. **Потоковый вывод** — события `thinking` пишутся в `stderr`, `text` — в `stdout`.
3. **Парсинг JSON** — строки обрабатываются построчно, небрежные строки игнорируются.
4. **Очистка сессий** — выполняется удалением `.jsonl` файлов и пустых директорий.
5. **Рекурсия при удалении** — пустые директории удаляются рекурсивно.
