# schema-to-prompt

## Обзор

Модуль `schema-to-prompt` предоставляет утилитарную функцию для преобразования `zod.ZodType` в текстовое описание ожидаемой JSON-структуры. Описание добавляется к пользовательскому промпту, чтобы агент знал формат ответа.

## Публичный API

### schemaToPrompt(schema: z.ZodType): string

Конвертирует заданную схему Zod в текстовое описание формата JSON.

**Параметры:**
- `schema` — схема Zod (любое подтипа: объект, массив, строка и т.д.)

**Возвращает:**
- `string` — текстовое описание формата, готовое к использованию в промпте

**Пример использования:**
```typescript
import { z } from "zod";
import { schemaToPrompt } from "./schema-to-prompt";

const schema = z.object({
  name: z.string(),
  age: z.number().optional(),
  tags: z.array(z.string())
});

const prompt = schemaToPrompt(schema);
// prompt будет содержать описание формата
```

## Реализация

Функция `schemaToPrompt` вызывает внутреннюю рекурсивную функцию `describeSchema`, которая проходит по узлам схемы и генерирует текстовое представление каждого типа.

### describeSchema(schema: z.ZodType, indent = 0): string

Внутренняя рекурсивная функция для описания схемы.

**Параметры:**
- `schema` — узел схемы Zod
- `indent` — уровень вложенности для форматирования (по умолчанию 0)

**Возвращает:**
- `string` — текстовое описание узла схемы

### Поддерживаемые типы Zod

| Тип Zod | Описание | Вывод |
|---------|----------|-------|
| `object` | Объект с полями | JSON с полями и типами |
| `array` | Массив элементов | `[тип, ...]` |
| `string` | Строка | `"string"` |
| `number` | Число | `"number"` |
| `boolean` | Булево | `"boolean"` |
| `null` | Ничего | `"null"` |
| `undefined` | Неопределено | `"undefined"` |
| `union` | Союз типов | `тип1 \| тип2 \| ...` |
| `enum` | Перечисление | `"строка1" \| "строка2" \| ...` |
| `literal` | Литерал | `JSON.stringify(значение)` |
| `tuple` | Кортеж | `[тип1, тип2, ...]` |
| `record` | Запись (объект-словарь) | `{ [key: string]: тип }` |
| `optional` | Опциональный | `тип (optional)` |
| `nullable` | Nullable | `тип \| null` |

### Обработка описаний

Если у узла схемы есть свойство `description`, оно используется как текстовое описание вместо автоматического вывода типа.

```typescript
z.string().describe("имя пользователя")
// будет выведено как "имя пользователя"
```

## Поведение

### Формат выходных данных

Возвращаемая строка всегда начинается с инструкций:
```
Respond in valid JSON only. No markdown fences, no commentary.
Expected format:
[описание схемы]

Your response must be VALID JSON matching this schema exactly.
```

### Отступы

Используется отступ для вложенных объектов. Каждый уровень добавляет 2 пробела.

### Неструктурированные типы

Если узел схемы не имеет `def`-свойства, возвращается строка `"unknown"`.

## Важные детали реализации

1. **Тип-объект**: используется `(schema as any).def` для доступа к внутренней информации схемы. Это обходное решение, так как типы `zod.ZodType` не имеют открытой структуры интерфейса.

2. **Рекурсия**: функция `describeSchema` обрабатывает вложенные структуры, включая объекты, массивы и союзы.

3. **Объединение описаний**: для типов `object`, `string`, `number` приоритет отдается свойству `description` из схемы перед выводом базового типа.

4. **Обработка union**: каждый вариант союза обрабатывается рекурсивно и соединяется через ` | `.

5. **Обработка enum**: извлекаются ключи `def.entries` и приводятся к JSON-строкам.

## Ограничения

- Не поддерживаются типы `intersection` (пересечение)
- Не обрабатываются преобразования (`z.preprocess`, `z.transform`)
- Простые типы без `description` всегда возвращают базовое имя типа

## Примеры

### Простой объект
```typescript
z.object({
  name: z.string(),
  age: z.number()
})
// {
//   name: string,
//   age: number
// }
```

### Объект с опциональными полями
```typescript
z.object({
  name: z.string(),
  age: z.number().optional()
})
// {
//   name: string,
//   age: number (optional)
// }
```

### Массив строк
```typescript
z.array(z.string())
// [string, ...]
```

### Союз типов
```typescript
z.union([z.string(), z.number()])
// string | number
```

### Nullable
```typescript
z.object({
  value: z.string().nullable()
})
// {
//   value: string | null
// }
```
